# Generative AI Chatbot

A Python-based Generative AI chatbot developed as part of my DecodeLabs internship using the OpenAI API.

## Features

* AI-powered conversational responses
* OpenAI API integration
* Python-based implementation
* Environment variable configuration

## Technologies

* Python
* OpenAI API
* Git & GitHub

## Setup

1. Clone this repository.
2. Install the required dependencies.
3. Create a `.env` file.
4. Add your OpenAI API key to the `.env` file.
5. Run `chatbot.py`.

## Note

The API key is stored locally in the `.env` file and is not included in this repository.
